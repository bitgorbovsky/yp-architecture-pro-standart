Таблица требований

| Код    | Требования                                                                                                                                                                                                                                                                                                                           | Комментарий |
| ------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| **F**  | **Функциональные (Functionality)**                                                                                                                                                                                                                                                                                                   |             |
|        | Клиент может видеть на сайте список доступных депозитных продуктов с актуальными ставками.                                                                                                                                                                                                                                           |             |
|        | Клиент может подать заявку на депозит через сайт, оставляя свой номер телефона и Ф.И.О.                                                                                                                                                                                                                                              |             |
|        | Регистрация клиентов с подтверждением личности и проверкой документов происходит только в отделениях банка. Процесс проводит управляющий клиентского офиса.                                                                                                                                                                          |             |
|        | Управляющий клиентского офиса может в рамках процесса идентификации обработать ранее поданную клиентом заявку на депозит с Ф.И.О. и номером телефона, регистрируя нового клиента в системе банка. При регистрации клиента система посылает СМС код на номер клиента. Клиент обязан сообщить этот код управляющему клиентского офиса. |             |
|        | Управляющий клиентского офиса вводит в систему СМС-код подтверждения регистрации, сообщённый ему клиентом. После этого система связывает все полученные данные в единую запись по клиенту.                                                                                                                                           |             |
|        | В интернет-банке могут выполнять действия только зарегистрированные клиенты.                                                                                                                                                                                                                                                         |             |
|        | В интернет-банке клиент может видеть список доступных депозитов со ставками, рассчитанными на сегодняшний день, а также со ставками, рассчитанными лично для него.                                                                                                                                                                   |             |
|        | В интернет банке клиент может подать заявку на открытие депозита, указывая счёт и сумму. После подачи заявки система присылает ему СМС-код на подтверждение заявки.                                                                                                                                                                  |             |
|        | В интернет-банке клиент вводит СМС-код для подтверждения ранее поданной заявки на открытие депозита.                                                                                                                                                                                                                                 |             |
|        | Управляющий клиентского офиса может создать от имени клиента заявку на депозит при обращении клиента в отделение банка, с указанием суммы депозита, номера счёта или планируемой суммы депозита. Клиенту приходит СМС-код для подтверждения заявки.                                                                                  |             |
|        | Управляющий клиентского офиса может ввести СМС-код для подтверждения заявки на депозит.                                                                                                                                                                                                                                              |             |
|        | Сотрудник отдела депозитов в АБС может обрабатывать заявки на создание депозитов. АБС может отобразить возможность согласования заявки на депозит по особым условиям, если у клиента есть счета, сумма денег на которых подходит под эти условия.                                                                                    |             |
|        | Сотрудник отдела депозитов в АБС может перевести заявку на депозит на этап анализа кредитного риска.                                                                                                                                                                                                                                 |             |
|        | Сотрудник отдела кредитов обрабатывает запрос на анализ кредитного риска в АБС, может корректировать рассчитанные данные по кредитному риску, сохранять это в заявке на депозит.                                                                                                                                                     |             |
|        | Сотрудник отдела депозитов может подтвердить условия, указанные в заявке на депозит. После подтверждения АБС создаёт депозит. Также АБС дополнительно размещает эту информацию в разделе, используемом сотрудниками отдела кредитов для расчёта ставок по депозитам.                                                                 |             |
|        | Сотрудник отдела кредитов может с помощью АБС, имеющей доступ к данным по депозитам и кредитам, расчитать ставку депозитов на текущий день.                                                                                                                                                                                          |             |
|        | Сотрудник отдела кредитов утверждает в АБС расчитанную ставку по депозитам на текущий день и ставка становится доступной для управляющих клиентского офиса, для отображения на сайте и в интернет банке.                                                                                                                             |             |
|        | Клиент получает СМС-уведомление о подтверждении условий депозита и его открытии.                                                                                                                                                                                                                                                     |             |
|        |                                                                                                                                                                                                                                                                                                                                      |             |
|        |                                                                                                                                                                                                                                                                                                                                      |             |
| **U**  | **Удобство использования (Usability)**                                                                                                                                                                                                                                                                                               |             |
|        | Необходимо применять сложившуюся систему дизайна интерфейсов, принятых для приложений, разрабатываемых в рамках банка. Клиент должен видеть привычные цвета и брендированные элементы, как в интернет банке, так и на сайте.                                                                                                         |             |
| **R**  | **Надёжность (Reliability)**                                                                                                                                                                                                                                                                                                         |             |
|        | Режим работы АБС - 24/7.                                                                                                                                                                                                                                                                                                             |             |
|        | Уровень доступности АБС - 99.9%.                                                                                                                                                                                                                                                                                                     |             |
|        | Режим работы Интернет-Банка - 24/7.                                                                                                                                                                                                                                                                                                  |             |
|        | Уровень доступности Интернет-Банка - 99.9%.                                                                                                                                                                                                                                                                                          |             |
|        | Необходимо наличие трёхкратного резервирования: 1 основной ЦОД и 2 резервных.                                                                                                                                                                                                                                                        |             |
|        | Переключение между ЦОДами проводится в полуавтоматическом режиме.                                                                                                                                                                                                                                                                    |             |
|        | Между основным и резервным ЦОДами должна быть настроена репликация и федерация данных.                                                                                                                                                                                                                                               |             |
| **P**  | **Производительность (Performance)**                                                                                                                                                                                                                                                                                                 |             |
|        | Отклик по всем операциям в интернет-банке должен длиться до 100 миллисекунд.                                                                                                                                                                                                                                                         |             |
|        | Время проведения платежей должно быть до 100 миллисекунд, вместе с выполнением сопутствующих служебных запросов.                                                                                                                                                                                                                     |             |
|        | Возможность горизонтального масштабирования всех компонентов системы, за исключением АБС.                                                                                                                                                                                                                                            |             |
|        | Необходимо обеспечить возможность вертикального масштабирования АБС.                                                                                                                                                                                                                                                                 |             |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                                                                                                                                                                                                                |             |
|        | Разработка документации для дальнейшего расширения системы.                                                                                                                                                                                                                                                                          |             |
|        |                                                                                                                                                                                                                                                                                                                                      |             |
| **+R** | **+ Ограничения (Restrictions)**                                                                                                                                                                                                                                                                                                     |             |
|        | Функциональность работы с СМС желательно реализовать силами команды разработки банка.                                                                                                                                                                                                                                                |             |
|        | Чувствительные данные по клиентам с сайта (номер телефона клиента и его Ф.И.О.) передаются в АБС по защищенным каналам связи с шифрованием трафика.                                                                                                                                                                                  |             |
|        | Обмен данными между АБС и интернет-банком происходит по защищённым каналам связи с шифрованием трафика.                                                                                                                                                                                                                              |             |
|        | Стек технологий Интернет-Банка: APS.NET MVC 4.5 .NET 4.5, СУБД MSSQL.                                                                                                                                                                                                                                                                |             |
|        | Стек технологий АБС: Delphi, СУБД Oracle, PL/SQL.                                                                                                                                                                                                                                                                                    |             |
|        | Стек технологий системы call-центра: интерфейс - React.JS, серверная часть - Java Spring Boot, СУБД - PostgreSQL.                                                                                                                                                                                                                    |             |
|        | Стек технологий сайта: интерфейс - React.JS, серверная часть - PHP.                                                                                                                                                                                                                                                                  |             |
|        | У сотрудников ИТ-отдела банка должен быть опыт работы с новыми технологиями разработки, начиная с языков программирования.                                                                                                                                                                                                           |             |
|        | Для реализации асинхронных процессов, для использования очередей желательно применять Kafka. При использовании Kafka необходимо обеспечить совместимость интернет-банка и АБС с ней.                                                                                                                                                 |             |
|        | Прямая работа с API АБС запрещена.                                                                                                                                                                                                                                                                                                   |             |
|        |                                                                                                                                                                                                                                                                                                                                      |             |
