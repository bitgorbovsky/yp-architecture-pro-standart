### <a name="_qmphm5d6rvi3"></a>**Решение**
Основная проблема - предложения по кредитам для зарегистрированных клиентов и предодобрения по кредитам для новых клиентов. Система Кредитного скоринга испытывает повышенную нагрузку в рабочие часы, при этом пик заявок на кредиты и предварительных заявок на кредиты тоже приходится больше на рабочие часы. Необходимо решение, которое позволяет не нагружать систему кредитного скоринга, либо повысить на неё нагрузку в допустимых пределах.
Основная идея решения заключается в том, чтобы выделить определённый набор правил для расчёта предодобренных кредитов в отдельный сервис. Данный сервис будет выполнять две задачи:
* обрабатывать поток предварительных заявок с сайта, если в них заполнены паспортные данные;
* поток потенциальных предложений по кредиту для клиентов для расчёта предложений, которые будут показываться клиенту в Интернет-Банке.
В обеих задачах качестве исходных данных будут использоваться данные по клиенту из БКИ, по которым можно, основываясь на сформулированных правилах расчёта предварительного одобрения, выдать предварительное одобрение кредита.
Процесс одобрения прямой кредитной заявки остаётся неизменным, и в рамках MVP проходит в режиме ручной обработки сотрудником отдела кредитов с помощью кредитного конвейера.

#### Новые сущности и компоненты
**Предварительная заявка на кредит** - предварительная заявка на крдеит, цель которой - обозначить намерение клиента зарегистрироваться в банке и получить кредит под выбранные условия. Генерируется незарегистрированными клиентами. При обработке П.З. клиент должен пройти процедуру идентификации в отделении банка. В течение жизненного цикла П.З. проходит через следующие системы:
* Сайт - П.З. создаётся через сайт.
* АБС - На основе П.З. в АБС создаются уже прямые заявки на кредит для зарегистрированных клиентов.
* Система кредитных предложений - 
Прямая заявка на кредит отличается от П.Я. на кредит тем, что проходит через процесс Кредитного конвейера и приводит непосредственно к выдаче кредита.

**Сервис кредитных предложений** - система, обрабатывающая предварительные заявки на кредит по стандартным правилам, а также генерирующая предварительные кредитные предложения для существующих клиентов по определённым правилам. Кредитное предложение является маркетинговым инструментом, повышающим продажи. Полноценное одобрение кредита всё равно происходит по стандартному процессу с Кредитным конвейером. Система Кредитного скоринга может учитывать данные по предварительным одобрениям.

**Основные изменения:**
* **Доработка АБС**
	* Разработка раздела предварительных кредитных заявок.
	* Разработка функции создания кредитных заявок на основе предварительных кредитных заявок.
* **Доработка ABSLoader**
	* Необходимо добавить синхронизацию данных по обработанным предварительным заявкам на кредит из системы Кредитных предложений, для дальнейшего создания заявок на кредит с дополнительными деталями.
* **Доработка IBLoader**
	* Загрузка данных по кредитным предложениям в БД Интернет-Банка.
* **Создание новых топиков Kafka**
	* Топик по банковским событиям: `Events` - содержит события по клиентам (регистрация клиентов) и по предварительным кредитным заявкам.
	* Топик по кредитным предложениям: `CreditProposals` - содержит созданные кредитные предложения для их дальнейшей синхронизации в И.Б.
	* Топик по кредитным заявкам: `CreditRequests` - содержит события создания кредитных заявок в И.Б.
	* Топик по предварительным кредитным заявкам: `CreditPreRequests` - поток предварительных заявок с сайта.
* **Расширение захвата данных из АБС через CDC**
	* Добавление захвата данных по предварительным кредитным заявкам
	* Добавление захвата данных по клиентам
* **Разработка сервиса кредитных предложений**
	* Сервис, на основе системы заложенных правила и информации из БКИ, рассчитывающий предварительное одобрение кредитных заявок для потенциальных клиентов и кредитных предложения для зарегистрированных клиентов клиентов.
