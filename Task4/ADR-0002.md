### <a name="_qmphm5d6rvi3"></a>**Решение**
В рамках начального решения по прототипу процесса предоставления депозита онлайн было предложение решение о синхронизации информации о текущих депозитных продуктах с актуальными на текущий день ставками на сайт из АБС.

**Требуемые доработки:**
1. Расширение API Сайта - добавить API для получения данных по депозитным продуктам и актуальным ставкам.
2. Расширение Сайта: добавить раздел для скачивания файла с депозитными продуктами и ставками. Файл формируется на основе данных, загруженных в СУБД сайта. Раздел должен быть защищён паролем, пароль сообщается сотрудникам партнёрского call-центра.
3. Расширение системы call-центра:
	1. Интеграция с новым API сайта для получения информации по продуктам и депозитным ставкам.
	2. Отображение информации по продуктам банка в системе call-центра.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
Рассматривалась прямая интеграция с АБС. Данное решение отклонено, т.к. при нагрузке на call-центр растёт и нагрузка на АБС.

**Недостатки, ограничения, риски**
Основной риск - сотрудники партнёрского call-центра могут забыть скачать файлы. Для обработки риска предлагается ввести небольшой организационный процесс - специально назначенный менеджер по работе с партнёрами каждый день связывается с партнёрским call-центром и проверяет, скачали сотрудники новый файл или нет. Сотрудник партнёрского call-центра, ответственный за работу с информацией по депозитным продуктам, выполняет рассылку на своих коллег с новым файлом.
